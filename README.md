# Catálogo de Livros Web

Versão web do [Catálogo de Livros](https://github.com/mpblima/catalogo-livros), mantida em um projeto independente da aplicação desktop.

## Estado do projeto

Repositório inicial. A aplicação web ainda não foi implementada; tecnologias, hospedagem e autenticação serão definidas na etapa de arquitetura.

## Referência funcional

O catálogo desktop serve como referência para o desenvolvimento da versão web:

- Acervo de livros digitais (PDF e EPUB) e físicos.
- Pesquisa por título, autor, editora e assunto e subassunto.
- Favoritos e livros em leitura, com atualização imediata dos filtros.
- Cadastro e edição de informações bibliográficas, capas e anotações.
- Registro do progresso de leitura.

Essa lista descreve a referência de funcionalidades, não recursos já disponíveis neste repositório.

## Dados pessoais

Livros, bancos de dados, capas pessoais, credenciais e configurações locais não devem ser versionados. Qualquer integração ou migração do acervo existente precisa ser definida e validada antes de alterar seus dados.
